스타 승자예측 관리툴 v2

[GitHub Pages]
1) 새 저장소를 만든다. 예: star-prediction
2) 이 압축파일의 index.html, manifest.webmanifest을 저장소 최상단에 업로드한다.
3) GitHub 저장소 → Settings → Pages
4) Build and deployment에서 Deploy from a branch 선택
5) Branch: main / (root) 선택 후 Save
6) 잠시 후 Pages에 표시되는 https://계정명.github.io/저장소명/ 주소로 접속

[iPhone]
- 위 GitHub Pages 주소를 Safari에서 연다.
- 공유 버튼 → 홈 화면에 추가
- 이후 앱 아이콘처럼 실행 가능

[PC]
방법 A: GitHub Pages 주소를 Chrome/Edge에서 사용
방법 B: index.html을 PC에 저장해 더블클릭해 직접 실행
- 기록은 해당 브라우저의 localStorage에 자동 저장됨

[중요]
- iPhone과 PC의 데이터는 자동 동기화되지 않는다.
- 같은 기록을 옮기려면 '백업'으로 JSON 저장 → 다른 기기에서 '복원' 사용.
- 브라우저 사이트 데이터 삭제 시 기록이 사라질 수 있으니 중요한 대회는 백업 권장.

기능
- 참가자 등록
- 대회명 설정
- 경기 추가 / 이전 대진 복사
- 참가자별 승자 선택
- 예측 마감 / 재오픈
- 실제 승자 입력 / 결과 취소
- 자동 채점 / 순위 / 적중률
- 경기 기록
- 자동저장
- JSON 백업 / 복원
- 모바일/PC 반응형 UI
